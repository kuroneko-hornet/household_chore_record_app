# 開発環境構築
## Node
### Mac
1. homebrewのインストール/アップデート
  ```shell
  # インストール
  $ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  # アップデート
  $ brew upgrade
  ```
2. nodeのインストール
  ```shell
  # インストール
  $ brew install node

  # アップデート
  $ brew upgrade node
  ```
